What happens to your data

  • PDF files (teachers). When a teacher converts a PDF, the file is sent through our server to an AI service (Anthropic) that reads it and returns the exercises. Vocabloom does not keep the PDF or the result: there is no database.
  • Access code (teachers). The code is kept in the browser tab only while it is open (session storage) and is sent with each conversion to check that you may use the tool.
  • Share links. The worksheet is stored inside the link itself, in the part after the #. That part is not sent to our server when a student opens the link.
  • Students. A student can type a name and answer the exercises. Answers, name and progress stay in that device’s browser (local storage) so the student can continue later. Nothing is sent to us. The “Copy my results” button only copies text to the clipboard, and the student decides whether to send it to the teacher.
  • Hosting logs. Our hosting provider ([hosting provider]) may record technical data such as IP address and time of each request, for security and to keep the service running.

Vocabloom sets no cookies, uses no analytics or advertising, and loads no fonts or scripts from other companies.

Please do not upload personal data

Worksheets should contain teaching material only. Do not upload files that contain names, photos, marks or other personal data of students or staff.

Why we process data and for how long

Purpose: to let teachers prepare interactive exercises. Legal basis: [for example, public task or legitimate interests, to be confirmed by the school].
